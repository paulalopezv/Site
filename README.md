# paulalopezv.com

Personal academic website for Paula Agustina López Villalba, built with
Next.js and deployed on Vercel.

## Prerequisites

- Node.js `>=20.9.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Structure

- `app/page.tsx` — page content (research sections, papers, abstracts)
- `app/layout.tsx` — page metadata (title, description, favicon)
- `app/globals.css` — styles
- `public/` — static assets (photo, CV, favicon)

## Deploy

Deployed via Vercel, connected to this GitHub repository. Pushing to `main`
triggers a new deployment automatically.
